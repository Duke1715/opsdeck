## OpsDeck 0.5.0 — модули, выбор ИИ-модели, видеокарта и первые внешние контрибьюторы

Первый релиз, в который вошёл код от сообщества. Спасибо всем, кто прислал PR! 🙌

🌐 Новый сайт с обзором и инструкцией: https://leoalecksey.github.io/opsdeck/

### ✨ Новое
- **Модули.** Кнопка ⊞ в колонке слева включает и выключает разделы галочками. Новая установка стартует с базовым набором: Терминал, Kubernetes, SSH, KeePass, Заметки. Выключенные разделы не загружаются. Если раздел нужен другому (например, SSH открывает терминал), он включится сам. У тех, кто обновляется, все разделы остаются включены.
- **Выбор модели локального ИИ.** Лёгкая Qwen2.5-Coder 1.5B (как раньше), Qwen3.5 4B и 9B, Qwen3.6 35B-A3B для мощных машин или свой файл `.gguf`. ★ подсказывает, что подходит по памяти. Модели скачиваются с проверкой контрольной суммы и удаляются по одной.
- **Ускорение на видеокарте.** Vulkan на Linux и Windows (NVIDIA, AMD, Intel), Metal на Mac. Крупные модели отвечают в разы быстрее. Если видеокарты нет, не хватает драйвера или видеопамяти, ИИ сам переключается на процессор и продолжает работать: запрос не теряется, вы просто получите уведомление.
- **Свой ИИ-сервер.** Вместо встроенного движка можно подключить Ollama, vLLM, LM Studio или любой сервер с OpenAI-совместимым API; API-ключ хранится в системном хранилище паролей, а OpsDeck предупреждает, если запросы уходят с компьютера. *(@Ranger-X)*
- **Векторные иконки.** Новый набор SVG-иконок вместо эмодзи по всему интерфейсу, единый стиль кнопок и полей. *(@artp1ay)*
- **OpenCode в AI-панели** рядом с Claude Code, Codex, Gemini и Aider. *(@artp1ay)*
- **Шрифт терминала.** Выбор из популярных моноширинных шрифтов (MesloLGS NF и Nerd Fonts для Powerlevel10k); неустановленные помечены, любой другой — через «Другой…». *(@Duke1715)*

### 🪟 Windows
- Служебные команды (git, terraform, ssh, ИИ) больше не мигают окнами консоли (#11). *(@UnQuaiz)*
- Вывод ping, tracert и nslookup на русской Windows читается правильно. *(@UnQuaiz)*
- Список SSH грузится при открытии раздела и запоминает результаты `ssh -G`: старт быстрее, окна OpenSSH не мелькают. *(@UnQuaiz)*
- `exit` в PowerShell закрывает панель сплита.

### 🍎 macOS
- Сборка подписывается без сертификата Apple (ad-hoc). Если macOS всё равно пишет «приложение повреждено», перетащите OpsDeck в «Программы» и выполните `xattr -cr /Applications/OpsDeck.app`.

### 🛠 Исправления и мелочи
- SSH: текст в строке хоста снова можно выделять, перетаскивание в группу начинается, когда уводите хост из строки.
- Строки деревьев в «Базах данных» и «Заметках» снова выровнены по левому краю.
- Закрыта уязвимость в зависимости сборки (source-map-js, GHSA-68fv-2mgg-jv7q).
